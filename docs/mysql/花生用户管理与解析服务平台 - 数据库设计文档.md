users (用户信息表)
表描述
存储平台用户的基本信息，包括登录凭证、余额等

字段说明
字段名	类型	约束	描述
id	BIGINT UNSIGNED	PRIMARY KEY, AUTO_INCREMENT	用户ID
email	VARCHAR(255)	NOT NULL, UNIQUE	邮箱账号（主登录凭证）
phone	VARCHAR(20)	UNIQUE	手机号（可选）
password_hash	TEXT	NOT NULL	加密后的密码
balance	INT	DEFAULT 0	当前可用余额（单位：解析次数）
experience_quota_used	BOOLEAN	DEFAULT FALSE	是否已领取新人体验额度
created_at	DATETIME	DEFAULT CURRENT_TIMESTAMP	注册时间
updated_at	DATETIME	DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP	更新时间
索引
PRIMARY KEY (id)
UNIQUE INDEX idx_email (email)
UNIQUE INDEX idx_phone (phone)
activation_codes (激活码表)
表描述
管理系统生成的各种面值激活码及其使用状态

字段说明
字段名	类型	约束	描述
code	CHAR(32)	PRIMARY KEY	激活码（唯一标识）
value	INT	NOT NULL	对应增加的解析次数
is_used	BOOLEAN	DEFAULT FALSE	是否已被使用
used_by_user_id	BIGINT UNSIGNED	NULL	使用者用户ID（外键关联 users.id）
used_at	DATETIME	NULL	使用时间
created_at	DATETIME	DEFAULT CURRENT_TIMESTAMP	创建时间
expired_at	DATETIME	NULL	过期时间（如有有效期控制）
索引
PRIMARY KEY (code)
INDEX idx_used_status (is_used)
INDEX idx_used_by_user (used_by_user_id)
FOREIGN KEY (used_by_user_id) REFERENCES users(id) ON DELETE SET NULL
parse_tasks (解析任务记录表)
表描述
记录用户发起的所有解析任务的详细信息和执行结果

字段说明
字段名	类型	约束	描述
id	BIGINT UNSIGNED	PRIMARY KEY, AUTO_INCREMENT	任务ID
user_id	BIGINT UNSIGNED	NOT NULL	发起用户的ID（外键）
platform_type	ENUM('普通平台', '高消耗平台', '动态计费平台')	NOT NULL	平台分类
parse_type	ENUM('单帖提取', '主页/批量提取')	NOT NULL	解析类型
input_url	TEXT	NOT NULL	输入的原始链接
status	ENUM('待解析','解析中','成功','失败')	DEFAULT '待解析'	任务状态
result_count	INT	DEFAULT 0	成功提取的内容数量
deducted_times	INT	DEFAULT 0	实际扣除的解析次数
reason	TEXT	NULL	若失败，则填写失败原因
created_at	DATETIME	DEFAULT CURRENT_TIMESTAMP	任务创建时间
finished_at	DATETIME	NULL	任务结束时间
索引
PRIMARY KEY (id)
INDEX idx_user_id (user_id)
INDEX idx_status (status)
INDEX idx_created_at (created_at)
FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
balance_logs (余额变动日志表)
表描述
详细记录每个用户余额的每一次变动，用于审计和追溯

字段说明
字段名	类型	约束	描述
id	BIGINT UNSIGNED	PRIMARY KEY, AUTO_INCREMENT	日志ID
user_id	BIGINT UNSIGNED	NOT NULL	关联用户ID
change_amount	INT	NOT NULL	变化量（正为充值，负为消费）
before_balance	INT	NOT NULL	变动前余额
after_balance	INT	NOT NULL	变动后余额
action_type	ENUM('充值','解析消费','管理员调整')	NOT NULL	行为类型
related_task_id	BIGINT UNSIGNED	NULL	关联解析任务ID（若有）
remark	TEXT	NULL	备注（比如激活码编号、手动调账说明）
created_at	DATETIME	DEFAULT CURRENT_TIMESTAMP	时间戳
索引
PRIMARY KEY (id)
INDEX idx_user_id (user_id)
INDEX idx_action_type (action_type)
INDEX idx_created_at (created_at)
FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
FOREIGN KEY (related_task_id) REFERENCES parse_tasks(id) ON DELETE SET NULL
admins (后台管理员表)
表描述
存储后台管理系统的管理员账户信息和权限等级

字段说明
字段名	类型	约束	描述
id	BIGINT UNSIGNED	PRIMARY KEY, AUTO_INCREMENT	管理员ID
username	VARCHAR(100)	NOT NULL, UNIQUE	登录用户名
password_hash	TEXT	NOT NULL	密码哈希
role	ENUM('普通管理员','超级管理员')	NOT NULL, DEFAULT '普通管理员'	权限等级
created_at	DATETIME	DEFAULT CURRENT_TIMESTAMP	创建时间
last_login_at	DATETIME	NULL	上次登录时间
索引
PRIMARY KEY (id)
UNIQUE INDEX idx_username (username)
INDEX idx_role (role)
platform_rules (平台规则映射表)
表描述
配置不同平台的解析类型和计费规则，便于程序动态判断

字段说明
字段名	类型	约束	描述
platform_name	VARCHAR(100)	PRIMARY KEY	平台名称
category	ENUM('普通平台','高消耗平台','动态计费平台')	NOT NULL	分类
single_deduction	INT	NOT NULL, DEFAULT 1	单帖提取扣费次数
batch_deduction_fixed	INT	NOT NULL, DEFAULT 2	固定扣费模式下的基础扣费次数
batch_deduction_formula	VARCHAR(255)	NULL	动态公式表达式（如 Ceil(n/3)）
索引
PRIMARY KEY (platform_name)
示例数据
('Instagram', '高消耗平台', 2, 2, 'CEIL(posts / 3)')
('YouTube', '动态计费平台', 1, 2, 'CEIL(posts / 3)')
('普通平台', '普通平台', 1, 2, NULL)
